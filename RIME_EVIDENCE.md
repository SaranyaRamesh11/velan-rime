# RIME Evidence

## Hard Voice Problem
Interruption and Recovery

## Claim
VELAN stops outdated speech when the farmer interrupts and processes the updated request without allowing stale audio to continue.

## Acceptance Test
1. Start a normal voice interaction.
2. Allow VELAN to begin speaking through Rime.
3. Interrupt VELAN while the audio is playing.
4. Provide a new question or updated information.

## Expected Result
The current audio should stop immediately. The previous request should be cancelled, and VELAN should process the new request and provide an updated response.
