# VELAN

## Voice-Enabled Land & Agricultural Navigator

### Problem
Farmers need quick, hands-free agricultural guidance while working in the field.

### Solution
VELAN is a voice-native AI farming companion that provides agricultural guidance through Tamil/Tanglish conversations.

### Key Innovation
VELAN focuses on interruption and recovery. When a farmer interrupts VELAN while it is speaking, the outdated audio is stopped and the new request is processed.

### Features
- Voice-first interaction
- Tamil/Tanglish support
- Farm condition monitoring
- Mock weather and soil data
- Rime-generated speech
- Interruption and recovery

### Architecture
Farmer Voice → Speech Recognition → Decision Logic → Rime TTS → Audio Playback

### Tech Stack
- HTML
- CSS
- JavaScript
- Browser Web Speech API
- Rime TTS API
